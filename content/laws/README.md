# Age-grade laws

One file per age group, named for the `ageGroup` in a team's `team.json` — `u14.md` serves a team with `"ageGroup": "u14"`. A team that writes its own `laws.md` overrides this like any other default.

The RFU's age-grade regulations are the same for every club in England, which is why these live here rather than in a team folder: worth getting right once.

**A team whose age group has no file here simply gets no laws page** — the build says so as a note and carries on. It is not an error, and it is a much better outcome than a page of invented regulations.

## Adding one

Copy `u14.md` as the shape, then write it from the **actual regulation text** — RFU Regulation 15 and its appendices, one per age group. Don't write it from memory or from a summary page; the figures in secondary sources disagree with each other often enough to matter, and a coach will plan contact load off what this page says.

Cover at least:

- What changes from the age group below — team size, pitch size, scrum, lineout, kicking, tackle height.
- Which of those changes are **genuinely new skills** rather than a step up from something the players already do. That is the part that should shape the first block of the season.
- The lineout format for this age group, and where it sits in the progression to fully contested.

Keep the frontmatter the same as `u14.md`'s, changing only `sub` and `card` to name the right age group.

**Age-grade regulations are reviewed each season.** Whatever is here was right when it was written; check it against the current regulation before the season starts.

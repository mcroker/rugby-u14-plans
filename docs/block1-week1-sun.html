Activities

Whole-group intervention — Lineout positioning + laws

Coaching Points: where each player stands in the line; lineouts are uncontested at U14 — no jumping/lifting, min 2 / max 13 players (see Laws of the Game (wiki)).

Setup: whole squad, cones marking the 5m and 15m lines.

Description: a short (2–3 min), single-voice coaching point delivered to everyone before the main game starts — not a specialist skill zone, everyone needs to hear this once.

Hooker throw-in (pull-out skill zone)

Coaching Points: accuracy, grip, release.

Setup: hookers peel off in a small group with a coach; everyone else continues handling work in the same window.

Description: repeated throw-ins at increasing distance/accuracy targets (e.g. cones marking front/middle/back of a 5-man line). Straight back into the main group once the essential-skills window ends.

Progressions: - Increase throw distance/height. - Add a receiver catching at each target.

Main game — Touch/tag, lineout restarts

Coaching Points: line-speed (defence); handling and support lines (attack); using the lineout restart cleanly.

Setup: small-sided, full pitch space (Sunday, so no need to compress into a third of a pitch as on Thursdays — see Coaching Notes (wiki)).

Description: small-sided touch/tag game where every restart is a lineout throw-in (uncontested). Defence scores points for line-speed (getting up as a line quickly); attack scores a bonus for a clean lineout catch that leads to a try.

Progressions: - Tighten the line-speed scoring window as the game goes on. - Layer in the Bang blitz-trigger call (see playbook.html) once the basic shape is running.

Adaptations: - Reduce grid width if line-speed is too easy to beat; widen it if defence is dominating.

Continuous Defence (backs, parallel to forwards' lineout work)

Coaching Points: quick reorganisation and communication under repeated pressure from alternating directions.

Setup: see Activities Bank (wiki).

Description: run as the backs' parallel focus while the forwards unit (plus hookers) is tied up in lineout work — this is the season's first blitz-defence exposure.

Tackle Diamond

Coaching Points: low — chop!, shoulder contact, squeeze (see Activities Bank (wiki)). Defence "wins" the rep if the tackle is completed over the halfway point of the diamond.

Setup: see Activities Bank (wiki).

Description: controlled, small-group, full-contact tackle-technique reps — short and sharp, then straight back into the main game.

Notes
